# Project Overview

## Problem statement
Patient details and consultation notes can become scattered across paper forms or separate files. This project demonstrates a structured digital workflow for registering patients and documenting consultation information.

## Objectives
1. Maintain a structured patient register.
2. Capture a dated case note for each patient.
3. Separate the user interface, API, shared types, and database model.
4. Provide a foundation for future authentication, role-based access, and audit features.

## Scope
The current starter supports patient registration and case-note API endpoints. The first frontend screen demonstrates patient registration and listing. It is not intended for real clinical deployment.

## Future enhancements
- Secure login and role-based permissions
- Patient search and profile view
- Case-note creation UI
- Audit trail and record export
- Automated tests and deployment pipeline
